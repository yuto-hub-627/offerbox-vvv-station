# LINE 連絡テンプレート

`{}` の部分を埋めて使う。送信はゆうとが手動で行う。
口調はやわらかめ、絵文字は1〜2個まで。

## 1. シフトの人への店頭案内のお願い
```
{名前}さん、今日のシフト（{開始}〜{終了}）よろしくお願いします！
キャリアフェス（{開催日}）の店頭案内、引き続きお願いします🙏
現在の予約は{現状人数}名、目標は{目標人数}名です。
就活が近そうな人（学年確認）を中心に声かけしてもらえると助かります！
```

## 2. SNS 投稿日のリマインド
```
{名前}さん、お疲れさまです！
今日（{日付}）は Instagram の投稿日です📱
・タイトル：{タイトル}
・形式：{形式}
投稿できたら一言もらえると嬉しいです！よろしくお願いします。
```

## 3. 集客MTG のリマインド
```
今日{時間}から集客MTGです！
前回決めたアクションの進捗を聞くので、担当の人は状況を教えてください🙏
議事録：{議事録リンク}
```
